# 蛋仔英语冒险 (Egg English Adventure)

## Problem Statement

> **HMW：如何让一个8-9岁零英语基础的中国三年级孩子，在暑假5-6周内，每天主动打开APP 20-30分钟，通过高度模仿蛋仔派对形态的闯关游戏，达成人教版PEP三年级上册的预习目标（掌握6个Unit79个核心词+23个句型+26字母拼读），同时家长获得客观学习报告？**

## Recommended Direction

**方向：蛋仔角色 + 赛季皮肤收集 + 每日速赛关卡，分两阶段推进。**

### 核心体验设计

孩子打开APP后第一件事：选择/创建自己的蛋仔角色（圆形Q弹蛋造型，选颜色+简单面部表情）。这个蛋仔就是整个预习冒险的主人公。

**第一阶段 MVP（2-3周）：每日闯关赛**
- 每天1个世界（World）=5个英语关卡，对应一个Unit的一日内容切片
- 关卡 = 20-40秒快速迷你挑战（听音选词、看图配对、跟读闯关、拼词跳跃），模仿蛋仔障碍赛的快节奏
- 答对 = 通过障碍 ✅；答错 = 弹回起点重来 🔄（不惩罚、鼓励反复尝试）
- 通关奖励 = ⭐星星 + 1件简单装扮（帽子/眼镜/背包/特效之一）
- 蛋搭子（AI伙伴）：每个孩子有一个AI英语伙伴蛋仔，闯关时在旁边用中文鼓励+用英语示范、偶尔说搞笑的话。蛋仔派对是真人社交，这里是AI陪伴情感锚点——蛋仔没有的东西

**第二阶段（验证后 +2-3周）：赛季皮肤系统**
- 6个Unit = 6个赛季世界。每完成一个Unit解锁一个赛季主题皮肤（例：Unit 3 Animals赛季 → 动物主题蛋仔皮肤）
- 收集图鉴：展示已解锁的所有皮肤/装扮，模仿蛋仔皮肤图鉴
- 稀有皮肤碎片机制：连续7天通关额外奖励限定皮肤碎片，集齐合成
- 段位系统：青铜🥚 → 白银🥚 → 黄金🥚 → 钻石🥚 → 蛋仔之王👑

### 家长端

极简报告推送（微信/浏览器通知）："今天BB蛋仔完成了5关✅，学会跟读Hello! My name is...🎤 3星通关！获得新装扮：闪电眼镜⚡" 每天一条，轻量不施压。

## Key Assumptions to Validate

- [ ] **孩子会因为蛋仔角色+装扮收集而每天主动打开APP。** 验证方式：MVP阶段做3天使用测试，看孩子是否会主动要求打开，而非被家长要求。
- [ ] **蛋仔风格的Q弹视觉能在Web技术中达到吸引力阈值。** 验证方式：先做一个蛋仔角色创建页的HTML原型，给孩子看，观察第一反应——"哇"还是"哦"。不通过不继续。
- [ ] **Web Speech API + 简单打分算法能给出让零基础孩子接受的跟读反馈。** 验证方式：对5-10个单词做跟读测试，对比人工评分和算法评分的一致性。
- [ ] **"每天5关20-30分钟"的节奏是可持续的。** 验证方式：第一周每日使用时长日志，看是低于15分钟（太短无效果）还是超过40分钟（过长可能厌烦）。
- [ ] **蛋搭子AI伙伴是加分项而非分心项。** 验证方式：做一个AB测试——有关卡带AI伙伴的和不带AI伙伴的，看孩子更愿意重复玩哪个版本。

## MVP Scope (Phase 1)

### In Scope （第一阶段只做这些）

1. **蛋仔角色创建页**：选颜色（5色）+基础表情（3种）+第一件衣服。1个HTML页面。
2. **Week1 + Week2 共10天关卡**：只做前两个Unit的关卡内容（10天×5关=50关），验证完整体验再补后4个Unit。
3. **5种挑战题型模板**：听音选图、看图选词、跟读打分、拖拽配对、字母拼读。每种题型一个通用引擎，喂不同内容即可。
4. **基础装扮系统**：10个装扮（帽子×3、眼镜×3、背包×2、特效×2），每关通关获得随机一个。
5. **蛋搭子AI伙伴（基础版）**：闯关时在屏幕角落出现，3种预设鼓励话术（中文）+跟读时英语示范。
6. **家长每日报告**：一条文字摘要（今日通关数+星级+新装扮+尝试的单词）。

### Out of Scope （第一阶段明确不做）

- 赛季主题皮肤系统 → Phase 2
- 段位排行榜系统 → Phase 2
- Unit 3-6 + Revision 关卡内容 → Phase 2验证后补
- 社交分享/好友PK → 不做（单人预习场景，不是社交游戏）
- 用户登录/注册/数据库 → MVP用localStorage，一个孩子一台设备足够
- 后台管理/关卡编辑器 → 不做（直接用教材内容硬编码+结构化数据）
- 动画短片/3D场景 → 不做（2D CSS动画模拟蛋仔Q弹感即可）
- iOS/Android原生APP → 不做（Web PWA，浏览器即可）

## Not Doing (and Why)

- **完整复刻蛋仔全部系统**（UGC工坊、多人对战、道具系统等）—— 这是英语预习工具，不是蛋仔克隆。只取最核心的两点：角色收集 + 快速闯关。
- **语法教学/单词拼写强制练习** —— 教学目标仅要求三年级上册为"听说认读"，不要求拼写。硬加拼写会毁了游戏感。
- **AI对话自由聊天** —— 零基础孩子无法进行开放式英语对话，强行AI对话会产生大量挫败感。限定在关卡内的"蛋搭子鼓励+示范"。
- **多平台同步/云存档** —— MVP阶段一台设备就够了。暑假预习场景不需要跨设备。
- **家长端强制管控（限时锁/远程关停/屏幕时间限制）** —— APP的定位是"孩子自己想去玩"，不是"家长管控工具"。加了管控就是给自己贴上"不是玩具"的标签。

## Open Questions

1. **蛋仔IP的视觉红线？** 网易对蛋仔角色形象有版权保护。我们的蛋仔角色要做到"一看就知道是蛋仔风格"但不侵权，具体美术边界是什么？需要咨询。
2. **Web Speech API在移动浏览器的兼容性？** 特别是微信内置浏览器、iOS Safari对SpeechRecognition和SpeechSynthesis的支持情况。这决定跟读打分能否以Web实现。
3. **6个Unit+Revision共7个模块，MVP只做2个Unit够验证核心假设吗？** 如果孩子完成第一周(Unit1)和第二周(Unit2)后仍然主动要求继续，就说明核心假设成立——再补余下的内容只是工作量而非不确定性。
4. **是否需要真人配音还是TTS就够？** 零基础孩子对语音质量敏感。一个发音不准的TTS可能直接让英语发音学习偏向错误。需测试当前TTS（浏览器内置或API）对教材词汇的发音准确性。
